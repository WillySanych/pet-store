Релиз {{ .Release.Name }} установлен в namespace {{ .Release.Namespace }}.

Поды:
  kubectl get pods -n {{ .Release.Namespace }} -w

Docker Desktop публикует LoadBalancer на localhost:
  http://localhost:8080/swagger-ui.html  — шлюз
  http://localhost:3000                  — Grafana, admin/admin
  http://localhost:9090                  — Prometheus

Если адрес не занят compose и всё равно не отвечает:
  kubectl port-forward -n {{ .Release.Namespace }} svc/api-gateway 8080:8080

Дашборды берутся из ConfigMap {{ index .Values "petstore-infra" "grafana" "dashboardsConfigMap" | default "petstore-dashboards" }}:
  kubectl create configmap petstore-dashboards -n {{ .Release.Namespace }} \
    --from-file=deploy/grafana/dashboards --dry-run=client -o yaml | kubectl apply -f -
